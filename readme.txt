【実行ファイル名】
Diff.exe

【概要】
構造色をシュミレーションしたものです

【操作方法】
スペース：サーファエイスの従法線変動(これによって表面の光の模様が変化します)
矢印キー :モデル回転

【工夫点】
構造色表現
頂点情報をダイナミックに変更させるための設計
クラス設計

【動作環境】 
ライブラリ：
Microsoft DirectX SDK (June 2010)

ＯＳ：
Windows XP ,Windows Vista, Windows 7.
　
ＣＰＵ：
上記OSの動作するCPU.
メモリ：
上記OSが動作するのに十分で，少なくとも64MB以上のRAM．

GPU :
Vertex Shader 4.0以上, Pixel Shader 4.0以上
